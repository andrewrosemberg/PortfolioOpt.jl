Formulations

PortfolioOpt.PortfolioFormulation — Type
PortfolioFormulation(sense, objective_terms, risk_constraints=RiskConstraint[])

Portfolio optimization problem: the objective is the weighted sum of the objective_terms (maximized or minimized according to sense), subject to the risk_constraints.

source
PortfolioOpt.ObjectiveTerm — Type
ObjectiveTerm(term::AbstractPortfolioTerm, weight=1.0, uid=uuid1())

Adds weight times the value of term (see calculate_measure!) to the objective.

source
PortfolioOpt.RiskConstraint — Type
RiskConstraint(measure::AbstractPortfolioTerm, set::Union{EqualTo,GreaterThan,LessThan}, uid=uuid1())

Constrains the value of measure (see calculate_measure!) to set, e.g. RiskConstraint(SqrtVariance(d), LessThan(0.02)).

source
PortfolioOpt.portfolio_model! — Function
portfolio_model!(model::JuMP.Model, formulation::PortfolioFormulation, w; record_measures=false)

Adds the objective terms and risk constraints of formulation to model, where w are the investment decision variables (e.g. created by market_model). The objective terms are added to the current objective of model.

If record_measures=true, returns a Dict from the uid of each term to the JuMP expression of its value; otherwise returns nothing.

source
PortfolioOpt.uid — Function
uid(term::Union{ObjectiveTerm,RiskConstraint}) -> UUID

Identifier of an objective term or risk constraint. It is the key of the term in the pointers returned by portfolio_model! (and build_portfolio_model) when record_measures=true.

source
PortfolioOpt.AbstractPortfolioTerm — Type
AbstractPortfolioTerm

Supertype of everything that can be evaluated on the portfolio decision variables, i.e. that can be used in an ObjectiveTerm or a RiskConstraint. Subtypes include PortfolioRiskMeasure and ConeRegularizer.

To add a new term, subtype it and implement calculate_measure!:

struct MyTerm <: AbstractPortfolioTerm end
PortfolioOpt.calculate_measure!(::MyTerm, w) = ... # JuMP expression or variable
source
PortfolioOpt.calculate_measure! — Function
calculate_measure!(term::AbstractPortfolioTerm, w) -> JuMP expression

Adds to the model that owns the decision variables w whatever auxiliary variables and constraints are needed to represent term, and returns a scalar JuMP expression (or variable) with its value for the portfolio w. The model is obtained from w (e.g. with JuMP.owner_model(first(w))).

This is the main extension point of the package: implement it for a new AbstractPortfolioTerm, or for an existing measure with a new ambiguity set (for example calculate_measure!(m::ExpectedReturn{<:MySet}, w)).

source
PortfolioOpt.CertaintyEquivalent — Type
CertaintyEquivalent(s::AmbiguitySet, utility::ConcaveUtilityFunction)

Certainty equivalent of the portfolio return R: the sure return with the same utility, $u^{-1}(\mathbb{E}[u(R)])$. Unlike ExpectedUtility it is in units of return. For an ExponentialUtility with risk aversion a it is minus the entropic risk measure,

\[CE(R) = -\frac{1}{a} \log \mathbb{E} [e^{-a R}]\]

which equals $\mu'w - \frac{a}{2} w' \Sigma w$ for a Gaussian distribution. It is concave in the portfolio, so maximize it or constrain it from below (GreaterThan).

source

Norm of the weighted portfolio, t such that [t; weight_matrix * w] in norm_cone, e.g. ConeRegularizer(MOI.NormOneCone(n + 1)) for an L1 penalty.

Utility functions

PortfolioOpt.ConcaveUtilityFunction — Type
ConcaveUtilityFunction

Supertype of the (concave) utility functions u of the portfolio return used by ExpectedUtility and CertaintyEquivalent: PieceWiseUtility and ExponentialUtility. A new utility needs a calculate_measure! method for the measures and ambiguity sets it supports.

source
PortfolioOpt.PieceWiseUtility — Type
PieceWiseUtility(c=[1.0], b=[0.0])

Concave piecewise linear utility of the portfolio return x,

\[u(x) = \min_{k} \; (c_k x + b_k),\]

the minimum of the affine functions with slopes c and intercepts b (vectors of the same length). The default is the identity, u(x) = x. It is implemented for ExpectedUtility over a MomentUncertainty set.

Examples

julia> u = PieceWiseUtility([1.0, 0.5], [0.0, 0.01]);

julia> coefficients(u), intercepts(u)
([1.0, 0.5], [0.0, 0.01])
source
PortfolioOpt.coefficients — Function
coefficients(u::PieceWiseUtility) -> Vector

Slopes $c_k$ of the affine pieces of u.

source
PortfolioOpt.intercepts — Function
intercepts(u::PieceWiseUtility) -> Vector

Intercepts $b_k$ of the affine pieces of u.

source
PortfolioOpt.ExponentialUtility — Type
ExponentialUtility(a)

Exponential (constant absolute risk aversion, CARA) utility of the portfolio return x with risk aversion a > 0:

\[u(x) = \frac{1 - e^{-a x}}{a}\]

It is a positive affine transformation of the classic $-e^{-a x}$, so the optimal portfolio is the same, and it tends to x (risk neutral) as a → 0. Use it in ExpectedUtility or CertaintyEquivalent. Both are represented with exponential cones (e.g. solved by Clarabel, SCS, Mosek) and are implemented for:

  • a Gaussian distribution (MvNormal), where $\mathbb{E}[e^{-a w'r}] = e^{-a \mu'w + a^2 w' \Sigma w / 2}$;
  • a Gaussian mixture (MixtureModel of MvNormals), the sum of the above weighted by the component probabilities (Luxenberg & Boyd, 2022);
  • samples (DeterministicSamples).

References:

  • Luxenberg, E., & Boyd, S. (2024). Portfolio construction with Gaussian mixture returns and exponential utility via convex optimization. Optimization and Engineering, 25, 555-574. https://doi.org/10.1007/s11081-023-09814-y

PortfolioOpt.BudgetSet — Type
BudgetSet{T<:Real, D<:ContinuousMultivariateSampleable} <: CenteredAmbiguitySet{T,D}

Bertsimas's uncertainty set:

\[\left\{ \mu \; \middle| \begin{array}{ll} s.t. \quad \mu_i \leq \hat{r}_i + z_i \Delta_i \quad \forall i = 1:\mathcal{N} \\ \quad \quad \mu_i \geq \hat{r}_i - z_i \Delta_i \quad \forall i = 1:\mathcal{N} \\ \quad \quad z_i \geq 0 \quad \forall i = 1:\mathcal{N} \\ \quad \quad z_i \leq 1 \quad \forall i = 1:\mathcal{N} \\ \quad \quad \sum_{i}^{\mathcal{N}} z_i \leq \Gamma \\ \end{array} \right\} \\\]

Attributes:

  • d::Sampleable{Multivariate, Continous}: The parent distribution with an uncertain mean
  • Δ::Array{Float64,1}: Uncertainty around mean. (default: std(d) / 5)
  • Γ::Float64: Number of assets in worst case. (default: 0.1 * length(d))

References:

  • Bertsimas, D. e Sim, M. (2004). The price of robustness. Operations research, 52(1):35–53.
source
PortfolioOpt.EllipticalSet — Type
EllipticalSet <: CenteredAmbiguitySet{T,D}

\[\left\{ \mu \; \middle| \begin{array}{ll} s.t. \quad \sqrt{(\hat{r} - \mu) ' \Sigma^{-1} (\hat{r} - \mu)} \leq \delta \\ \end{array} \right\} \\\]

Atributes:

  • d::Sampleable{Multivariate, Continous}: The parent distribution with an uncertain mean
  • Δ::Array{Float64,1}: Uniform uncertainty around mean. (default: 0.025)

References:

  • Ben-Tal, A. e Nemirovski, A. (2000). Robust solutions of linear programming problems contaminated with uncertain data. Mathematical programming, 88(3):411–424.
source
PortfolioOpt.MomentUncertainty — Type
MomentUncertainty <: CenteredAmbiguitySet

MomentUncertainty(d, γ1, γ2)
MomentUncertainty(d, γ1, γ2, lower, upper)
MomentUncertainty(d; γ1, γ2, lower=nothing, upper=nothing)

Distributions of the returns $r$ whose first two moments are close to those of the nominal distribution d (with mean $\hat{r}$ and covariance $\Sigma$), and, optionally, whose support is contained in the box $[\underline{r}, \overline{r}]$:

\[\left\{ P \; \middle| \begin{array}{ll} s.t. \quad (\mathbb{E}_P [r] - \hat{r}) ' \Sigma^{-1} (\mathbb{E}_P [r] - \hat{r}) \leq \gamma_1 \\ \quad \quad \mathbb{E}_P [ (r - \hat{r}) (r - \hat{r})' ] \preceq \gamma_2 \Sigma \\ \quad \quad P(\underline{r} \leq r \leq \overline{r}) = 1 \\ \end{array} \right\} \\\]

Atributes:

  • d::Sampleable{Multivariate, Continous}: The nominal distribution (only its mean and covariance are used).
  • γ1::Float64: Uncertainty around the mean (has to be greater than or equal to 0).
  • γ2::Float64: Uncertainty around the covariance (has to be greater than or equal to 1).
  • lower::Vector, upper::Vector: Bounds of the support of the returns (default: -Inf and Inf, i.e. unbounded support). Infinite entries are not bounded. The mean of d has to be inside the box.

The worst case measures implemented over this set are ExpectedUtility with a PieceWiseUtility, ExpectedReturn and ConditionalExpectedReturn (minus the worst case CVaR), all reformulated as semidefinite programs (SDP).

With unbounded support the reformulations are exact (Delage & Ye, 2010). With a bounded support, the constraint "for every return in the box" is handled with one nonnegative multiplier per finite bound (as in Yang et al., 2014), which gives a conservative approximation: the value is a lower bound of the exact worst case and is never smaller than the value with unbounded support.

References:

  • Delage, E., & Ye, Y. (2010). Distributionally robust optimization under moment uncertainty with application to data-driven problems. Operations Research, 58(3), 595-612. https://doi.org/10.1287/opre.1090.0741
  • Yang, L., Li, Y., Zhou, Z., & Chen, K. (2014). Distributionally robust return-risk optimization models and their applications. Journal of Applied Mathematics, 2014, 784715. https://doi.org/10.1155/2014/784715
source
PortfolioOpt.DuWassersteinBall — Type
DuWassersteinBall <: CenteredAmbiguitySet

\[\left\{ r \; \middle| \begin{array}{ll} s.t. \quad d_w(P, \hat{P}_N) \leq \epsilon \\ \quad \quad || \xi || \leq \Lambda \\ \quad \quad [\xi; 0] + [0_{m x 1}; \Lambda] \in K \\ \quad \quad K = {[\omega, \pi] \in R^m x R: \pi \geq ||\omega||^*} \\ \end{array} \right\} \\\]

Atributes:

  • d::DeterministicSamples: Samples from the parent distribution
  • ϵ::Float64: Wasserstein distance from sampled distribution (has to be greater than 0). (default: 0.01)
  • Λ::Float64: Uncertainty around sampled values (has to be greater than 0). (default: maximum(d))

References:

  • NingNing paper on Wasserstein DRO (Corollary 1-3): https://ieeexplore.ieee.org/abstract/document/9311154
source
PortfolioOpt.primal_cone — Function
primal_cone(::Val{p}) -> Type{<:MOI.AbstractVectorSet}

Cone {(t, x) : t ≥ ||x||_p} of the p norm used by DuWassersteinBall. Implemented for p = 1.0, 2.0 and Inf; add a method for Val{p} (with p a Float64) to support another norm.

Markets

PortfolioOpt.PortfolioMarket — Type
PortfolioMarket

Supertype of markets in which the decision is the vector of amounts invested in each asset (the bids). VolumeMarket is the implementation shipped with the package.

A new market type has to implement:

  • num_assets(market): number of assets;
  • market_budget(market) and set_market_budget(market, value): money available;
  • bids(market) and set_bids!(market, bids): current investment decision;
  • clear_market!(market, prices): sets the realized returns of the assets;
  • total_profit(market): profit of the current bids after the market is cleared.

and can optionally implement market_model (the default is a long only portfolio within the budget). With these, build_portfolio_model, change_bids!(market, formulation, optimizer), the recorders and sequential_backtest_market work with the new market.

The interface does not depend on other packages. When OptimalBids is loaded, its change_bids!, clear_market! and calculate_profit functions also accept any PortfolioMarket (package extension).

PortfolioOpt.market_model — Function
market_model(market::PortfolioMarket, optimizer_factory; sense, model=Model(optimizer_factory)) -> (model, w)

Creates (or fills model with) the variables and constraints of an investment in market and returns the model and the vector w of amounts invested per asset (length num_assets(market)). Any objective added here (e.g. the risk free return of the money that is not invested) must use sense; the formulation terms are added on top of it by portfolio_model!.

The default method creates a long only portfolio, w ≥ 0 and sum(w) ≤ market_budget(market), with no objective. Implement it for a new market type to change the feasible set.

PortfolioOpt.build_portfolio_model — Function
build_portfolio_model(market::PortfolioMarket, formulation::PortfolioFormulation, optimizer_factory;
    record_measures=false, model=Model(optimizer_factory)) -> (model, w, pointers)

Builds, without solving, the JuMP model of formulation in market: market_model followed by portfolio_model!. Returns the model, the investment variables w and the pointers to the value of each term (nothing unless record_measures=true).

Use it to add constraints before solving, then solve and set the bids with change_bids!(market, model, w):

model, w, _ = build_portfolio_model(market, formulation, optimizer)
@constraint(model, w .<= 0.3 * market_budget(market)) # position limits
change_bids!(market, model, w)

PortfolioOpt.portfolio_weights — Function
portfolio_weights(formulation::PortfolioFormulation, num_assets::Integer, optimizer_factory;
    budget=1.0, volume_fee=0.0, allow_short_selling=false, risk_free_rate=0.0
) -> Vector{Float64}

Solves formulation on a fresh VolumeMarket with num_assets assets and returns the optimal amount invested in each asset (the portfolio weights when budget = 1.0). Whatever is not invested is held in the risk-free asset.

The keyword arguments are passed to the VolumeMarket constructor. If the solver does not find an optimal solution, a warning is emitted and a vector of zeros is returned (see change_bids!).

Example (returns is a T × N matrix of past returns, one row per period):

d = MvNormal(vec(mean(returns; dims=1)), cov(returns))
formulation = PortfolioFormulation(MAX_SENSE,
    ObjectiveTerm(ExpectedReturn(d)), RiskConstraint(SqrtVariance(d), LessThan(0.02)),
)
w = portfolio_weights(formulation, size(returns, 2), Clarabel.Optimizer)
