Extending PortfolioOpt

PortfolioOpt is built around a few abstract types and functions that can be extended from your own code, without changing the package:

To addSubtypeImplement
a term of the objective or of a constraintAbstractPortfolioTermcalculate_measure!
a risk measure over a distribution or ambiguity setPortfolioRiskMeasurecalculate_measure!
an ambiguity setCenteredAmbiguitySetdistribution, and calculate_measure! for the measures that use it
a way to estimate the distribution of returnsAbstractForecasterforecast
a marketPortfolioMarketnum_assets, market_budget, set_market_budget, bids, set_bids!, clear_market!, total_profit, and optionally market_model
a history of prices for backtestsMarketHistorypast_prices, current_prices, market_template, num_assets
a quantity recorded in backtestsStateRecorderrecord!, get_records

Remember to extend the functions of the package (PortfolioOpt.calculate_measure!(...) = ...), not to define new functions with the same name.

A new ambiguity set

The worst case expected return over a box around the mean, $\{\mu : |\mu_i - \hat{r}_i| \leq \delta\}$, is $\hat{r}'w - \delta \|w\|_1$. To use it, subtype CenteredAmbiguitySet and implement calculate_measure! for ExpectedReturn over the new set. The function receives the investment variables w, adds whatever variables and constraints it needs to their model, and returns the value of the measure as a JuMP expression.

using PortfolioOpt, Distributions, Clarabel, LinearAlgebra

struct BoxSet{T<:Real,D<:Sampleable} <: CenteredAmbiguitySet{T,D}
    d::D
    δ::T
end

PortfolioOpt.distribution(s::BoxSet) = s.d

function PortfolioOpt.calculate_measure!(m::ExpectedReturn{<:BoxSet}, w)
    model = JuMP.owner_model(first(w))
    s = ambiguityset(m)
    t = @variable(model)
    @constraint(model, [t; w] in MOI.NormOneCone(length(w) + 1))
    return dot(mean(s), w) - s.δ * t
end

It can now be used like the ambiguity sets of the package:

d = MvNormal([0.010, 0.012, 0.008], Diagonal([0.02, 0.03, 0.01] .^ 2))
optimizer = optimizer_with_attributes(Clarabel.Optimizer, "verbose" => false)

formulation = PortfolioFormulation(MAX_SENSE,
    ObjectiveTerm(ExpectedReturn(BoxSet(d, 0.005))),
    RiskConstraint(SqrtVariance(d), LessThan(0.015)),
)
w = portfolio_weights(formulation, 3, optimizer)

A new risk measure is the same: subtype PortfolioRiskMeasure (or AbstractPortfolioTerm if it does not depend on a distribution) and implement calculate_measure!. Both can be used in an ObjectiveTerm and in a RiskConstraint.

A new market

A PortfolioMarket holds the money available and the current investment. The default market_model is a long only portfolio within the budget; implement it to change the feasible set (e.g. short selling or fees, as in VolumeMarket).

mutable struct CashMarket <: PortfolioMarket
    n::Int
    budget::Float64
    bids::Union{Vector{Float64},Nothing}
    returns::Union{Vector{Float64},Nothing}
end
CashMarket(n; budget=1.0) = CashMarket(n, budget, nothing, nothing)

PortfolioOpt.num_assets(m::CashMarket) = m.n
PortfolioOpt.market_budget(m::CashMarket) = m.budget
PortfolioOpt.set_market_budget(m::CashMarket, v) = (m.budget = v)
PortfolioOpt.bids(m::CashMarket) = m.bids
PortfolioOpt.set_bids!(m::CashMarket, b::AbstractVector) = (m.bids = collect(Float64, b))
PortfolioOpt.clear_market!(m::CashMarket, r::AbstractVector) = (m.returns = r)
PortfolioOpt.total_profit(m::CashMarket) = dot(m.bids, m.returns)

The formulations, the recorders and sequential_backtest_market only use these functions, so they work with the new market. build_portfolio_model returns the model before it is solved, which is useful to add constraints that are not part of the formulation, such as position limits:

market = CashMarket(3)
model, w, _ = build_portfolio_model(market, formulation, optimizer)
@constraint(model, w .<= 0.4 * market_budget(market))
change_bids!(market, model, w)
bids(market)

Extending from another package

The interfaces above have no dependencies beyond the core of PortfolioOpt (JuMP, MathOptInterface and Distributions), so a package that adds richer market types or stronger formulations only needs to depend on PortfolioOpt: subtype PortfolioMarket, PortfolioRiskMeasure, CenteredAmbiguitySet or AbstractForecaster, and add methods to the functions of PortfolioOpt as in the examples on this page. Integrations with optional packages (TimeSeries, MarketData, OptimalBids) are package extensions, loaded only when those packages are.

Forecasts from past returns

A forecaster turns a T × N matrix of past returns (one row per period) into a distribution or an ambiguity set. EmpiricalGaussian and EmpiricalSamples are included, and a new one only needs forecast:

using Random
Random.seed!(1)

struct DiagonalGaussian <: AbstractForecaster end
PortfolioOpt.forecast(::DiagonalGaussian, returns::AbstractMatrix) =
    MvNormal(vec(mean(returns; dims=1)), Diagonal(vec(var(returns; dims=1))))

past_returns = rand(d, 60)' # T × N
samples = forecast(EmpiricalSamples(30), past_returns) # N × 30 samples
formulation = PortfolioFormulation(MAX_SENSE,
    ObjectiveTerm(ExpectedReturn(forecast(DiagonalGaussian(), past_returns))),
    RiskConstraint(ConditionalExpectedReturn(samples; α=0.1), GreaterThan(-0.05)),
)
portfolio_weights(formulation, 3, optimizer)
